- Big Buck Bunny MP4: readyState 4, currentTime 22.738 → 83.767, error null, пауза по OK.
- Проверена конкретная раздача со снимка пользователя: «Игра престолов», сезон 1, WEB-DL 2160p HDR10/Dolby Vision Hybrid, файл S01E01, около 9.5 ГиБ.
- На ТВ: readyState 4, paused false, duration 3696.119, currentTime 9.136 → 34.024 → 46.870, error null.

Предыдущая оговорка об отсутствии проверки аппаратного воспроизведения ниже относится к первой сборке 0.1.0. ## Браузерный тест интерфейса

В локальном приложении, подключённом к тому же внешнему TorrServer:

1. Поиск Big Buck Bunny в VilkaDB: результаты, сиды, размеры, качество.
2. Выбор реальной magnet-раздачи: TorrServer получил метаданные, приложение отобразило правильный файл.
3. Официальный открытый фильм: `https://webtorrent.io/torrents/big-buck-bunny.torrent`, файл №2 / Big Buck Bunny.mp4.
4. У плеера `readyState=4`, `paused=false`, `error=null`, `duration=634.6`; время реально увеличивается, кадр отображается.
5. Перемотка вправо на 30 секунд и пауза: позиция 1:25, отображается соответствующий кадр.
6. После выхода история сохранила 1:25. Нажатие сохранённой записи возобновило просмотр; после продолжения получено `currentTime=129.68`.
7. Живые запросы диапазонов 0–4095 и 100000–104095 вернули HTTP 206, корректный Content-Range и по 4096 байт.

Тестовые раздачи Big Buck Bunny оставлены во внешнем TorrServer, их можно использовать для проверки с телевизора.

## Автоматические проверки

`npm run check` — синтаксис backend и ES5 frontend.

`npm test` — 6 тестов:

- двойное экранирование реальных Rutor magnet и дедупликация hash;
- разбор метаданных FXML без исполнения разметки;
